## 3. Defects

Fixed in this audit (each with a regression test):

| ID | Sev | Defect | Fix |
|---|---|---|---|
| HDW-01 | High | **After any quotation state command (submit/accept/convert), the dirty-check flagged a phantom unsaved change — "Save draft before submitting."** blocked Convert/Submit until a full page reload; the sample journey dead-ends there | Command responses now sync the pristine snapshot (`syncOriginal`, DocumentView + `useQuotationCommands`); regression covered by the browser journey test |
| HDW-02 | High | **Quotations created via the UI could not record container requirements** — the config declares the grid, but `quotationTabs()` never rendered it; conversion therefore prepared zero boxes for UI-made quotes | "Containers" tab restored to the quotation editor (`document-tabs.ts`); unit test updated |
| HDW-03 | High | **Actual-container grid lost typed characters** ("TGHU1234567" committed as "T"/"H" etc.): `tableColumnSignature` serialized live `optionItems` (bound to the rows being typed), so the signature changed **per keystroke**, cell renderers were rebuilt and the focused input remounted | Options excluded from the signature; cells read items via the live descriptor; grid writes now debounced (trailing 400 ms) and merged **in place** so write round-trips never wipe typed-ahead values |
| MED-01 | Medium | `DELETE /service-orders` with financial history surfaced the raw FK violation as **HTTP 500** | Clean 409s: `ORDER_HAS_FINANCIAL_DOCUMENTS`, `ORDER_HAS_JOURNAL_ENTRIES`, `ORDER_HAS_SERVICE_CHARGES` with operator guidance; regression test |
| MED-02 | Medium | After deleting a converted Service Order, its quotation was **permanently undeletable** (dangling `quotation_conversions` row) | Dangling conversion links are cleared; quotation deletable once its order is gone; regression test extended |
| MED-03 | Medium | **Service-order detail payload omitted `quotationNo`/`quotationId`** (list had it) — payment/quote-derived grids rendered "No data"/$0 after refresh or deep-link | Detail resolves and returns the quotation link like the list; regression via E2E |

Open, unresolved (to plan before client acceptance):

| ID | Sev | Finding |
|---|---|---|
| DEF-01 | Medium | Keystrokes typed at machine speed into a fresh **empty** prepared container row can still be dropped after an in-flight write (probe evidence: "TGHU123" of 11). Human-speed typing verified accumulating and persisting. Root: controlled-input round trip across `UTable`/Nuxt UI `UInput`. Watch with `form-typing.spec.ts` conventions; candidate fix = uncontrolled number cell + commit on blur/Enter |
| DEF-02 | Medium | Reference pickers and list endpoints cap at `page_size` 200 silently — with 344 fee types the master-data dropdowns cannot reach older records (search still works). Needs server-driven lookup/search in pickers at scale |
| DEF-03 | Medium | The quotation **create** form's header action is labelled "Submit" (i18n `freight.moduleActions.submitQuotation`) but performs a draft save; label/behavior mismatch confuses users |
| DEF-04 | Low | A locally-refused duplicate container number leaves the row empty again — the typed value is not kept on the blocked row |
| DEF-05 | Low | `delete_draft_documents` silently returns 200 with fewer removed (non-draft rows ignored) instead of reporting what was skipped |
| DEF-06 | Low | The `.s01-db-url.txt` dev credential remains in Git history — rotate the dev DB password |
