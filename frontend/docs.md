# LCS Freight Forwarding

នេះសម្រាប់ **បុគ្គលិកប្រើប្រចាំថ្ងៃ**៖ លក់ ប្រតិបត្តិការ ហិរញ្ញវត្ថុ។ ពន្យល់គ្រប់ទំព័រតាមលំដាប់របារខាងឆ្វេង ជាភាសាខ្មែរសាមញ្ញ។

អ្នកមើលឃើញតែទំព័រដែលតួនាទីរបស់អ្នកអនុញ្ញាត។ បើមិនមានម៉ឺនុយ សូមអ្នកគ្រប់គ្រងពិនិត្យតួនាទី។

**អ្នកប្រើស្តង់ដារ** បើកបានទំព័រប្រតិបត្តិការ ហិរញ្ញវត្ថុ ទិន្នន័យមេ របាយការណ៍ និង **អ្នកប្រើ** / **តួនាទី** (មើលតែប៉ុណ្ណោះ)។ ការកំណត់រចនាសម្ព័ន្ធ ការកំណត់ប្រព័ន្ធ អង្គភាព សាខា លំដាប់លេខឯកសារ និងកំណត់ហេតុសវនកម្ម — សម្រាប់អ្នកគ្រប់គ្រង។

## 1. ចាប់ផ្តើម

### ចូលប្រព័ន្ធ

1. បើកកម្មវិធី។
2. បញ្ចូល **អ៊ីមែល** និង **ពាក្យសម្ងាត់**។
3. ជ្រើស **ចងចាំខ្ញុំ** បើចង់ឲ្យអ៊ីមែលត្រូវបានបំពេញពេលបន្ទាប់។
4. ជ្រើស **ខ្មែរ** នៅអេក្រង់ចូលប្រព័ន្ធ រួចចុចចូល។

### គណនីសាកល្បង (ប្រព័ន្ធបឋម)

ប្រើគណនីខាងក្រោមសម្រាប់សាកល្បង។ **មិនបង្ហាញគណនីអ្នកគ្រប់គ្រង** — សូមទាមទារពីអ្នកគ្រប់គ្រងប្រព័ន្ធ។


| តួនាទី               | អ៊ីមែល              | ពាក្យសម្ងាត់ | ទំព័រដែលបើកបាន                                                                                                          |
| -------------------- | ------------------- | ------------ | ----------------------------------------------------------------------------------------------------------------------- |
| **អ្នកប្រើស្តង់ដារ** | `user@gmail.com`    | `123456`     | ផ្ទាំងគ្រប់គ្រង, សម្រង់តម្លៃ, បញ្ជាសេវាកម្ម, ថ្លៃសេវា, ហិរញ្ញវត្ថុ, របាយការណ៍, ទិន្នន័យមេ, អ្នកប្រើ (មើល), តួនាទី (មើល) |
| **ហិរញ្ញវត្ថុ**      | `finance@gmail.com` | `123456`     | ផ្ទាំងគ្រប់គ្រង, ថ្លៃសេវា, ឯកសារហិរញ្ញវត្ថុ, គណនី, របាយការណ៍ហិរញ្ញវត្ថុ                                                 |


**អ្នកប្រើស្តង់ដារ** — ធ្វើបានទាំងប្រតិបត្តិការ និងហិរញ្ញវត្ថុភាគច្រើន មើលអ្នកប្រើ/តួនាទីបានតែមិនកែ។

**ហិរញ្ញវត្ថុ** — ផ្តោតលើថ្លៃសេវា ឯកសារហិរញ្ញវត្ថុ ចុះបញ្ជី គណនី របាយការណ៍ហិរញ្ញវត្ថុ។ **មិន** បើកសម្រង់តម្លៃ បញ្ជាសេវាកម្ម ឬទិន្នន័យមេ។

### ភ្លេចពាក្យសម្ងាត់

1. បើក **ភ្លេចពាក្យសម្ងាត់**។
2. បញ្ចូលអ៊ីមែល រួចស្នើកូដ។
3. បញ្ចូល **កូដ ៦ ខ្ទង់**។
4. កំណត់ពាក្យសម្ងាត់ថ្មី (យ៉ាងហោច ៦ តួ) រួចចូលម្តងទៀត។

### រចនាបថអេក្រង់


| តំបន់            | តួ                                                                                                 |
| ---------------- | -------------------------------------------------------------------------------------------------- |
| **របារខាងឆ្វេង** | ទំព័រទាំងអស់ដែលអ្នកបើកបាន។ អេក្រង់តូច — របារបង្រួមដោយស្វ័យប្រវត្តិ។                                |
| **របារខាងលើ**    | ចំណងជើង ផ្ទុកឡើងវិញ ប៊ូតុង `**⋯`** ម៉ឺនុយអ្នកប្រើ។ លើកំណត់ត្រា — **មុន / បន្ទាប់** និងត្រឡប់បញ្ជី។ |
| **តំបន់កណ្តាល**  | បញ្ជី ទម្រង់ របាយការណ៍។                                                                            |
| **របារខាងស្តាំ** | មតិយោបល់ សកម្មភាព (ពេលមាន)។                                                                        |


### ម៉ឺនុយអ្នកប្រើ (ខាងលើស្តាំ)

- **ប្រវត្តិរូប**
- **ភាសា** (ខ្មែរ)
- **ទំហំអក្សរ**
- **របៀបពន្លឺ / ងងឹត**
- **អំពី**
- **ចេញ**

### ស្វែងរក

ប្រអប់ស្វែងរកក្បាលទំព័រ ឬ **Ctrl+K** / **Cmd+K**។

### អ្វីដែលអ្នកមិនឃើញ

ម៉ឺនុយត្រងតาม **សិទ្ធិ** អង្គភាព និងសាខា។ ការលាក់ម៉ឺនុយមិនមែនសុវត្ថិភាពពេញ — ប្រព័ន្ធពិនិត្យពេលបើកកំណត់ត្រា។

## 2. របៀបបញ្ជី និងកំណត់ត្រា

### ទំព័របញ្ជី

- **ស្វែងរក** — លេខ ឈ្មោះ ពាក្យគន្លឹះ។
- **តម្រង** — អតិថិជន សាខា ស្ថានភាព កាលបរិច្ឆេទ។
- **ថ្មី** — បង្កើត (បើមានសិទ្ធិ)។
- **ផ្ទុកឡើងវិញ** — ផ្ទុកបញ្ជីឡើងវិញ។

តារាង៖ ជួរតូច ស្ថានភាព **badge** លុយ **ខាងស្តាំ** `**⋯`** នៅជួរ។

### ទំព័រកំណត់ត្រា

- **ផ្ទាំង** ចែកផ្នែក
- **អត្ថបទជំនួយ** ក្រោមគ្រប់វាល — អានមុនបំពេញ
- តារាងជួរ **បន្ថែម** និង `**⋯`**

### ច្បាប់ទូទៅ

- ទំហំវាល **មធ្យម**។
- លេខឯកសារផ្លូវការ (សម្រង់តម្លៃ ថ្លៃសេវា ...) — **ប្រព័ន្ធចេញ** មិនវាយដោយដៃជាលេខចុងក្រោយ។
- ប្រអប់បញ្ជាក់មុនលុប ចុះបញ្ជី បិទរយៈពេល។

## 3. លំដាប់ការងារប្រចាំថ្ងៃ

```text
សម្រង់តម្លៃ (ព្រាង → បានផ្ញើ → ទទួលយក)
        ↓ បម្លែង
បញ្ជាសេវាកម្ម (ផ្លូវ កុងតឺន័រ ឯកសារ ឯកសារភ្ជាប់)
        ↓ ថ្លៃពាណិជ្ជកម្ម
ថ្លៃសេវា (ព្រាង → ចេញ)
        ↓ បង្កើតវិក្កយបត្រ
ឯកសារហិរញ្ញវត្ថុ (ព្រាង → ចុះបញ្ជី)
        ↓
ទិនានុប្បវត្តិបានចុះ → របាយការណ៍ហិរញ្ញវត្ថុ
```


| សកម្មភាព                      | ប្រតិបត្តិការ?    | របាយការណ៍គណនី?      |
| ----------------------------- | ----------------- | ------------------- |
| រក្សា/ផ្ញើសម្រង់តម្លៃ         | បាទ               | ទេ                  |
| **ចេញ** ថ្លៃសេវា              | បាទ (ពាណិជ្ជកម្ម) | **ទេ**              |
| **ចុះបញ្ជី** ឯកសារហិរញ្ញវត្ថុ | បាទ               | **បាទ** (រយៈពេលបើក) |

| **កុងតឺន័រ**           | តម្រូយការ + **កុងតឺន័រជាក់ស្តែង** · **ទម្ងន់សរុប ≥ សរុប** |
| **ផ្ទាំងក្រុមសមាសភាគ** | ទម្រង់ឌីណាមិក (ពន្ធ វិក្កយបត្រ បញ្ជីទំនិញ ...)            |

### បោះពុម្ព — កុងតឺន័រជាក់ស្តែង

នៅផ្ទាំង **កុងតឺន័រ** → តារាង **កុងតឺន័រជាក់ស្តែង** → `**⋯`** នៅជួរ → **បោះពុម្ពប័ណ្ណឥណពន្ធ** (បោះពុម្ព DCN ស្វ័យប្រវត្តិ មួយកុងតឺន័រមួយប័ណ្ណ)។

### ផ្ទាំង


| ផ្ទាំង        | ការងារ                                                                    |
| ------------- | ------------------------------------------------------------------------- |

| **ជួរថ្លៃ**   | បន្ទាត់ថ្លៃ · **បោះពុម្ពវិក្កយបត្រ** នៅក្បាលតារាង (វិក្កយបត្រពន្ធទាំងជួរ) |

### លេខថ្លៃ

- **មានបញ្ជាសេវា** — លេខថ្លៃចេញដោយស្វ័យប្រវត្តិពីលំដាប់លេខ (មើលតែប៉ុណ្ណោះ)។

### លំដាប់គណនីត្រឹមត្រូវ

```text
ថ្លៃសេវា → បង្កើតវិក្កយបត្រ → ព្រាង → ចុះបញ្ជី → ទិនានុប្បវត្តិ
```

## យោងរហ័ស — គួរធ្វើ / មិនគួរធ្វើ

**គួរធ្វើ**

- រក្សាទិន្នន័យមេឲ្យត្រឹមត្រូវមុនសម្រង់តម្លៃ
- ផ្ញើ → ទទួល → បម្លែង (តាមលំដាប់)
- បំពេញឯកសារតាមផ្ទាំងទិសដៅ
- **ចេញ** ថ្លៃសេវា រួច **បង្កើត** វិក្កយបត្រ **ចុះបញ្ជី**
- បិទរយៈពេលគណនីពេលចុះបញ្ជីរួច

**មិនគួរធ្វើ**

- កែសម្រង់ **បានផ្ញើ** — បង្កើតកំណែថ្មី
- បម្លែងសម្រង់មិនទាន់ **ទទួលយក**
- គិតថា **ចេញ** ថ្លៃសេវា = ចុះគណនី
- ចុះបញ្ជីក្នុងរយៈពេល **បិទ**
- វាយលេខឯកសារផ្លូវការដោយដៃ
- ដាក់លេខគណនីធនាគារពេញ ឬពាក្យសម្ងាត់ក្នុងចំណាំ
